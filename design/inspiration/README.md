# Inspiration

Drop reference images here (Pinterest saves, screenshots, photos, sketches). Any file names are fine.

- `ui/` — menus, books, dialogue boxes, buttons, fonts, game screens you like
- `world/` — towns, places, buildings, lighting
- `characters/` — the reader, the demons, other people
- `mood/` — colors, weather, textures, anything that feels right

A short note next to an image helps a lot, for example `cozy-library.jpg` + `cozy-library.txt` saying "I like the warm light, not the clutter".

When this is filled in, the UI and the 3D look get redesigned from it.
